# week5 요청 발생기

Docker Compose로 실행한 발생기가 week6의 Kubernetes API에 요청을 보냅니다.

1. week6의 `web` 서비스를 PC의 8080 포트에 연결합니다. 연결한 PowerShell 창은 열어 둡니다.
2. 새 PowerShell에서 아래 명령을 실행합니다.

```powershell
Set-Location .\sender
docker compose up -d --build
```

3. <http://localhost:8090>에서 **프로젝트 검색** 또는 **소개글 분량 검사**를 선택하고, 분당 요청 수를 설정한 후 **요청 시작**을 누릅니다.
4. <http://localhost:8080>에서 요청 수와 Pod 수를 확인합니다.

| 요청 설정 | 확인할 변화 |
| --- | --- |
| 40건/분 | API Pod 1개 |
| 120건/분 | 최근 60초 요청이 안정되면 3개 |
| 220건/분 | 최근 60초 요청이 안정되면 5개 |
| 요청 중지 | 측정 구간에서 요청이 줄어든 후 최소 1개로 축소 |

각 단계에서 충분히 기다립니다. **설정한 요청 수**와 **실제 성공한 요청 수**를 함께 확인하세요. Pod 생성에는 시간이 필요합니다.

연결 실패가 나오면 week6 실행과 8080 포트 연결을 확인합니다. 발생기의 8090 포트와 수신 프로젝트의 8080 포트를 구분하세요.

종료할 때 `sender` 폴더에서 실행합니다.

```powershell
docker compose down
```

슬라이더의 최대값은 분당 250건입니다. 요청은 한 작업 스레드가 순서대로 보내며, 응답이 늦을 때 밀린 요청을 몰아서 보내지 않습니다.
